# CLAUDE.md

Before writing any code in this repository, read both of these files in full:

1. `docs/Instructions.md` — rules, conventions, structure, build commands.
2. `docs/decisions.md` — architectural decisions and open questions.

The non-negotiable rules in `docs/Instructions.md` always apply. If a task
conflicts with them, or depends on an `OPEN` question in `docs/decisions.md`,
stop and say so instead of guessing.
